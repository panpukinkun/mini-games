# 計画：掛け算忍者の九九音声を「童謡風・連声込み」の正しい読み方へ

## 背景・目的
掛け算忍者（`kakezan/index.html`）の九九の読み上げが、現代の学校読み（よん/なな/きゅう）になっているため、伝統的な「くくのうた」として正しく響かない。親・子どもになじみのある正しい唱え方（いん/し/しち/く ＋ 連声）に修正する。

## リサーチ結論（出典が一致）
以下の3者が **81通りすべてで完全一致** することを確認：
- 童謡童話王国「九九の歌」(douwa-douyou.jp)
- 山野さと子「99のうた」(uta-net.com)
- ACTABA 算数 (actaba.acmatu.com / actaba.sakura.ne.jp)

採用する読み（連声の例）：
- `2×2 = ににんがし`
- `3×3 = さざんがく`
- `3×6 = さぶろくじゅうはち`
- `3×8 = さんぱにじゅうし`
- `4×8 = しはさんじゅうに`
- `5×9 = ごっくしじゅうご`
- `6×9 = ろっくごじゅうし`
- `8×8 = はっぱろくじゅうし`
- `8×9 = はっくしちじゅうに`

**実装方針**：連声は「さん+はち→ぱ」「ろく+く→っく」「はち+はち→はっぱ」等の音変化で規則化が脆いため、信頼できる出典の **81通りルックアップ表** で実装する（計算ルールではなくハードコード表が確実）。

### 置換後のコード（抜粋）
```js
  // 九九の読み方（童謡風・連声込みの正しい暗唱。出典：童謡童話王国「九九の歌」/ 山野さと子「99のうた」/ ACTABA）
  // KUKU[a][b] = a×b の唱え方。「が」の前が因数、後が答え。
  const KUKU = {
    1: {1:"いんいちがいち",2:"いんにがに",3:"いんさんがさん",4:"いんしがし",5:"いんごがご",6:"いんろくがろく",7:"いんしちがしち",8:"いんはちがはち",9:"いんくがく"},
    /* ... 上記テーブルをそのまま埋め込み ... */
    9: {1:"くいちがく",2:"くにじゅうはち",3:"くさんにじゅうしち",4:"くしさんじゅうろく",5:"くごしじゅうご",6:"くろくごじゅうし",7:"くしちろくじゅうさん",8:"くはしちじゅうに",9:"くくはちじゅういち"}
  };
  // 出題時：答えを言わず「〜が」まで
  function kukuQuestion(a, b) {
    const s = KUKU[a][b];
    return s.slice(0, s.indexOf("が") + 1);
  }
  // 誤答時など：正答ごと読み上げ
  function kukuFact(a, b) {
    return KUKU[a][b];
  }
```

## 検証手順（実装後）
1. **構文チェック**：`node -e` で `kakezan/index.html` の `<script>` を抽出し構文エラーがないか確認。
2. **表の整合チェック（Node）**：各 `(a,b)` について `KUKU[a][b]` の「が」以降（答え部分）をかな→数値へ復元し、実際の `a*b` と一致するか自動検証（タイポ検出）。かな→数値マップ例：
   - `いち=1,に=2,さん=3,し=4,ご=5,ろく=6,しち=7,はち=8,く=9`、`じゅう` は「現在の累積×10」。
   - `にじゅうし`→20+4=24, `しじゅうご`→40+5=45, `はちじゅういち`→80+1=81 等。
3. **実機確認**：デプロイ後、Mac / Android / ChromeOS / Win / iOS それぞれで「3の段」「8の段」等を実際に聞き、連声（さざん / さんぱ / はっぱ / はっく 等）が正しく再生されるか確認。
